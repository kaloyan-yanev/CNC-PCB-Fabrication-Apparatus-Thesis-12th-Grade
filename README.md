# CNC-PCB-Fabrication-Apparatus-Thesis-12th-Grade
An automated CNC machine for fabricating double-sided PCBs, using a combined laser and drill head. The laser ablates a pre-applied paint coating on both copper layers to form an etching mask. The board is then drilled using the drilling head and finally etched to create the copper tracks.  In the current iteration, plated vias are not possible.
